# Веб-приложение «Лесная гавань»

Учебный проект для курсовой работы по теме «Разработка веб-приложения для базы отдыха».

## Возможности

- регистрация и вход пользователя;
- каталог домиков, коттеджей, номеров и глэмпинга;
- фильтрация каталога по типу проживания и вместимости;
- бронирование по датам с расчётом количества ночей и стоимости;
- серверная проверка пересечения дат, чтобы не допустить двойного бронирования;
- личный кабинет с историей заявок и отменой ожидающей заявки;
- панель администратора со статистикой, управлением каталогом и статусами бронирований;
- адаптивная вёрстка, уведомления, CSRF-токены, хеширование паролей и подготовленные SQL-запросы.

## Технологии

PHP 8.2+, MySQL 8.0+, PDO, HTML5, CSS3, JavaScript ES6, Bootstrap 5.3.3.

## Запуск

1. Установить локальный веб-сервер (например, XAMPP) с PHP и MySQL.
2. Скопировать папку проекта в каталог веб-сервера.
3. Открыть phpMyAdmin или MySQL-клиент и выполнить файл `database/schema.sql`.
4. При необходимости изменить параметры подключения в `config.php` или задать `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS` через окружение.
5. Убедиться, что корнем сайта является папка проекта, после чего открыть `http://localhost/`.

Для встроенного сервера PHP можно выполнить из папки проекта:

```bash
php -S 127.0.0.1:8000
```

Затем открыть `http://127.0.0.1:8000/`.

## Структура проекта

```text
admin/              панель администратора
assets/css/         стили
assets/js/          сценарии браузера
assets/img/         изображения и иллюстрации
database/           SQL-схема и тестовые данные
includes/           общие функции, шапка и подвал
config.php          подключение к БД
index.php           главная страница
catalog.php         каталог
room.php            карточка варианта проживания
register.php        регистрация
login.php           вход
booking.php         бронирование
profile.php         личный кабинет
```

## Примечание

В проекте используется учебная тестовая база. Платёжная система, отправка SMS/e-mail и реальная система управления размещением не подключены. Изображения и названия объектов являются демонстрационными. Папка `preview/` содержит статические HTML-макеты и снимки экранов для пояснительной записки; они не заменяют запуск PHP-приложения с MySQL.
